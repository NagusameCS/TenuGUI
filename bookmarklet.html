TenuGUI · edit this page

The editor is embedded in the bookmarklet. No server, account or extension. It edits the page in front of you using that page's own CSS and HTML; it does not inject TenuGUI textures, content.json or MCP state. Sites with a strict content security policy can block bookmarklets.

  1. Make sure the bookmarks bar is visible in your browser.
  2. Drag the TenuGUI · edit this page button onto the bar.
  3. Open any page, click the bookmark, then click elements to select them. Drag to move; double-click text to edit.
  4. Use the inspector for text, colours, spacing, links and images.
  5. Use Export HTML in the TenuGUI bar when you are done.
